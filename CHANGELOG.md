# Changelog

## 1.1.0 (2026-10-07)
- Start page to choose between the in-line and the off-axis simulator; switch without losing settings.
- In-line simulator: WebGPU engine with a start-up correctness and speed check, CPU fallback.
- Grid sizes 1064, 2048 and 2128 px (Bluestein FFT for non-power-of-two sizes).
- Collapsible parameter panels.
- Installable web app with offline cache; Electron desktop wrapper; GitHub Actions for Pages and the Windows build.
- Theory document for the lens + pinhole configuration with computed figures.
